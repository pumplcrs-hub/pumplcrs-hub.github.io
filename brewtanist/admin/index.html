แก้ข้อความ เปลี่ยนรูป
ไม่ต้องแก้โค้ด

ใช้ Pages CMS แก้เนื้อหาในแบบฟอร์ม แล้วบันทึกกลับเข้า GitHub หน้าเว็บจะอัปเดตหลัง GitHub Pages สร้างและเผยแพร่เวอร์ชันใหม่สำเร็จ

เปิดหน้าแก้ไข Pages CMSดูเว็บไซต์จริง

เริ่มใช้ครั้งแรก

  1. กด เปิดหน้าแก้ไข Pages CMS แล้วเลือก Sign in with GitHub ใช้บัญชี pumplcrs-hub
  2. ถ้าระบบขอให้ติดตั้ง Pages CMS GitHub App ให้เลือก Only select repositories แล้วอนุญาตเฉพาะ pumplcrs-hub.github.io ไม่ต้องเลือกทุก repo
  3. เปิด repo pumplcrs-hub/pumplcrs-hub.github.io และเลือก branch main จะพบเมนูแก้ไข 7 หมวดที่เตรียมไว้
  4. เลือกหมวด แก้ข้อมูลหรือรูป แล้วกด Save การบันทึกบน main เป็นการอัปเดตเว็บจริง ไม่ใช่แค่บันทึกร่าง

การเชื่อม GitHub กับ ChatGPT ไม่ได้ล็อกอิน Pages CMS ให้โดยอัตโนมัติ คุณต้องอนุญาต Pages CMS ด้วยตัวเองครั้งแรก ไม่ต้องส่งรหัสผ่านหรือ Token ในแชต

อยากแก้ตรงไหน เลือกเมนูนี้

เมนูสิ่งที่แก้ได้
01 · หน้าบนและเรื่องราวหัวเรื่อง คำแนะนำร้าน รูปใหญ่หน้าแรก ปุ่ม เนื้อหา Brew + Botanist และภาพข้างข้อมูลติดต่อ
02 · กาแฟและเบเกอรี่ภาพและข้อความการ์ด Espresso, Pour Over และ Matcha/Bakery เพิ่มหรือเปลี่ยนลำดับการ์ด
03 · สินค้าและภาพ 3Dชื่อสินค้า Tasting notes ระดับคั่ว ภาพ Render และสีพื้นหลังของแต่ละตัว
04 · เรื่องโรงคั่วข้อความขั้นตอนและภาพโรงคั่วจริง ช่องรูปเว้นว่างไว้จนกว่าจะมีภาพที่ต้องการ
05 · แกลเลอรีรูป คำบรรยาย ลำดับ และการซ่อนรูปโดยไม่ลบไฟล์
06 · คำถามที่พบบ่อยเพิ่มและแก้คำถาม-คำตอบ ส่วนที่อยู่และเวลาเปิดดึงจากข้อมูลร้าน
07 · ข้อมูลร้าน ลิงก์ และ SEOเบอร์โทร ที่อยู่ เวลาเปิด วิธีชำระเงิน Social links ชื่อและคำอธิบายหน้าเว็บสำหรับ Google

เปลี่ยนรูปให้ตรงตำแหน่ง

เปิดหมวดที่ต้องการ กดช่องรูป แล้วเลือกภาพเดิมในคลัง หรืออัปโหลด JPG, PNG, WebP จากเครื่อง รูปจะเก็บใน brewtanist/assets ไม่ต้องเปิดแชร์ไฟล์ Google Drive

ช่อง จุดครอปภาพ ใช้เลือก center กลางภาพ, top ด้านบน, bottom ด้านล่าง, left ด้านซ้าย หรือ right ด้านขวา ภาพสินค้า 3D แสดงเต็มภาพโดยไม่ครอป

หัวข้อ ตำแหน่งภาพหน้าแรกบนคอมพิวเตอร์ สลับภาพซ้ายหรือขวาได้ บนมือถือจะเรียงข้อความก่อนภาพเพื่อให้อ่านง่าย

เปลี่ยนลำดับรูปหรือการ์ดในรายการของ CMS และใช้สวิตช์ แสดง เพื่อซ่อนชั่วคราว ดีกว่าลบรูปที่ตำแหน่งอื่นยังใช้อยู่

รูปและข้อความที่บันทึกใน repo นี้เป็นข้อมูลสาธารณะ ใช้เฉพาะภาพที่ร้านมีสิทธิ์เผยแพร่ ห้ามใส่เอกสารส่วนตัว รหัสผ่าน หรือข้อมูลลูกค้า

หลังบันทึก

กดดูลิงก์สถานะด้านล่าง เมื่อ pages build and deployment ของการแก้ไขล่าสุดขึ้นเครื่องหมายถูก ให้เปิดเว็บจริงแล้วรีเฟรช ตรวจทั้งมือถือและคอมพิวเตอร์

ดูสถานะเผยแพร่บน GitHub Actions ↗ดูประวัติการแก้ไข ↗

ถ้า Build ขึ้นสีแดง เว็บเวอร์ชันเดิมยังอยู่ อย่าบันทึกซ้ำหลายครั้ง ให้ตรวจข้อความผิดพลาดก่อน ถ้าแก้ผิด ให้เปิดไฟล์นั้นใน GitHub → History → ดูเวอร์ชันก่อนหน้า แล้วนำค่าที่ถูกต้องกลับไปบันทึกใน CMS

หน้านี้เป็นคู่มือและทางเข้าเครื่องมือ ไม่ใช่ฟอร์มล็อกอิน ผู้เข้าชมทั่วไปที่ไม่มีสิทธิ์ใน GitHub ของคุณจะบันทึกแก้เว็บไซต์ไม่ได้ การกด Save ใน CMS ต้องผ่านสิทธิ์ของ GitHub
